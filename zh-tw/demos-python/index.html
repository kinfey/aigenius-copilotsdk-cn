    Python 示範¶

    以下內容導覽 src/AgentOrchestrator-python/README.md中的 Python 程式碼。閱讀這些內容，可了解 Agent HQ 示範的 FastAPI 版本如何運作；而 Python 實作 則提供對應的實作練習。

    導覽¶

    # 文件 涵蓋內容
    01 Copilot SDK 整合 CopilotChatService — 用戶端生命週期、工作階段事件、從回呼到佇列的串流處理，以及執行階段模型探索
    02 SSE 串流 app.routers.chat → 瀏覽器：傳輸格式、 StreamingResponse、錯誤合約
    03 零售分析 SQLModel 模型、SQLite、初始資料植入、預測、驗證，以及刻意保留的程式碼異味
    04 網頁使用者介面 靜態 HTML、原生 JavaScript、模型選擇器、localStorage 與串流呈現

    建議順序¶

    如果您剛接觸 Python 技術堆疊，請依編號順序閱讀；每篇內容都假設您已讀過前一篇。如果您已熟悉 .NET 路線，請從 SDK 整合頁面開始，並快速瀏覽 Python 與 .NET 的差異。

    ⚠️ 關於刻意保留的程式碼異味¶

    導覽 03 記錄了四種有缺陷的模式；這些模式 刻意保留，用於程式碼檢閱示範，並不是要修正的錯誤。Python 服務與 .NET 服務相互對應，因此適用相同的參考答案。
