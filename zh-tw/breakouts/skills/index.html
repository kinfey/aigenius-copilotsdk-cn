    技能¶

    本頁說明位於下列路徑中的五項儲存庫技能： .github/skills/。技能是可重複使用的知識套件；當要求符合特定領域、慣例或驗證工作流程時，Copilot 可加以呼叫。

    資料夾慣例¶

    每項技能位於：

    .github/skills/<skill-name>/SKILL.md

    SKILL.md 開頭的 frontmatter 至少包含 name 與 description。部分技能也會宣告 license 或 model。本文則提供領域規則、範例、檢查清單與輸出格式。

    技能、代理程式與指示的差異¶

    • 技能 是特定主題的參考資料，會教導 Copilot 如何處理特定類型的工作，例如產生前端或檢閱 ML 模型。
    • .github/agents/ 中的代理程式是具名角色，擁有自己的工具、提示，有時也會固定使用特定模型。
    • 指示檔案 例如 .github/copilot-instructions.md 與 .github/copilot-review-instructions.md 提供廣泛的儲存庫情境，可套用於多項工作。

    brand-guidelines¶

    • 路徑：.github/skills/brand-guidelines/SKILL.md
    • Frontmatter 名稱：brand-guidelines
    • Frontmatter 說明：「引導 AI 代理程式產生具有品牌風格的航空與忠誠度計畫網站。建立行銷頁面、產品目錄、主視覺區段、忠誠度點數顯示，或任何面向航空公司與常旅客情境的客戶介面時，請使用此技能。此技能提供完整的視覺設計系統，涵蓋色彩、字體排印、間距、元件與版面配置模式。」
    • 其他 frontmatter：license: MIT
    • 涵蓋內容：色彩權杖、字體排印、間距、產品卡片、忠誠度點數顯示、導覽、行動號召按鈕、主視覺區段、頁尾，以及品牌合規檢查清單。
    • Copilot 的呼叫時機：當要求建立或檢閱品牌行銷頁面、產品目錄、忠誠度點數使用者介面、主視覺區段，或面向客戶的航空公司／常旅客體驗時。

    data-pipeline-conventions¶

    • 路徑：.github/skills/data-pipeline-conventions/SKILL.md
    • Frontmatter 名稱：data-pipeline-conventions
    • Frontmatter 說明：「強制執行零售分析資料管線的程式撰寫慣例。撰寫或檢閱 ETL 程式碼、資料擷取、轉換邏輯或資料品質檢查時，請使用此技能。內容涵蓋生產環境資料管線的結構描述管理、等冪性、驗證、分割與可觀測性模式。」
    • 其他 frontmatter：license: MIT
    • 涵蓋內容：等冪 ETL、結構描述管理、驗證、無法處理訊息的處置、分割、批次處理、可觀測性、資料品質檢查、命名慣例與管線測試。
    • Copilot 的呼叫時機：當撰寫或檢閱零售分析的 ETL 程式碼、資料擷取、轉換、結構描述演進、驗證或資料品質檢查時。

    • 其他 frontmatter：license: MIT

    • Copilot 的呼叫時機：進行現場示範前、更新示範文件後、檢查示範正確性時，或有人要求驗證功能可用性時。

    frontend-conventions¶

    • 路徑：.github/skills/frontend-conventions/SKILL.md
    • Frontmatter 名稱：frontend-conventions
    • Frontmatter 說明：「引導 AI 代理程式從頭產生前端網站。建立 HTML 頁面、使用 CSS 設定樣式、加入 JavaScript 互動功能或建置靜態網站時，請使用此技能。內容涵蓋語意化 HTML5、現代 CSS 模式、無障礙功能、效能，以及可用於生產環境前端的元件模式。」
    • 其他 frontmatter：license: MIT、model: gpt-5.4
    • 涵蓋內容：語意化 HTML5、地標、標題階層、CSS 自訂屬性、Grid、Flexbox、回應式字體排印、行動裝置優先中斷點、元件模式、無障礙功能、效能、JavaScript 模式，以及前端檢閱檢查清單。
    • Copilot 的呼叫時機：當要求建立網站、到達頁面、靜態前端、HTML/CSS/JavaScript 頁面，或檢閱前端程式碼的無障礙功能或效能時。

    ml-model-review¶

    • 路徑：.github/skills/ml-model-review/SKILL.md
    • Frontmatter 名稱：ml-model-review
    • Frontmatter 說明：「檢閱 ML 模型程式碼的正確性、公平性與生產就緒程度。撰寫或檢閱客戶分群、預測模型、特徵工程或模型評估程式碼時，請使用此技能。它會檢查零售分析 ML 管線中的資料外洩、偏差、可重現性與部署風險。」
    • 其他 frontmatter：license: MIT
    • 涵蓋內容：資料外洩、特徵工程、可設定的臨界值、評估指標、偏差與公平性檢查、可重現性、生產就緒程度、漂移監控，以及 ML 檢閱檢查清單。
    • Copilot 的呼叫時機：當撰寫或檢閱客戶分群、預測模型、特徵工程、模型評估或零售分析 ML 管線程式碼時。
