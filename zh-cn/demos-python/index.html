    Python 演示¶

    src/AgentOrchestrator-python/README.md 中 Python 代码的演练讲解。阅读这些内容可了解 Agent HQ 演示的 FastAPI 版本如何工作；Python 实验则提供相应的动手实践。

    演练讲解¶

    # 文档 覆盖范围
    01 Copilot SDK 集成 CopilotChatService — 客户端生命周期、会话事件、回调到队列的流式传输、运行时模型发现
    02 SSE 流式传输 app.routers.chat → 浏览器：传输格式、StreamingResponse、错误契约
    03 零售分析 SQLModel 模型、SQLite、种子数据、预测、验证以及刻意存在的代码异味
    04 Web 界面 静态 HTML、原生 JavaScript、模型选择器、localStorage、流式渲染

    建议顺序¶

    如果您初次接触 Python 技术栈，请按编号顺序阅读；每篇内容均以前一篇为基础。如果您已熟悉 .NET 路线，可从 SDK 集成页面开始，并快速浏览 Python 与 .NET 之间的差异。

    ⚠️ 有意保留的代码异味¶

    演练讲解 03记录了四种为代码评审演示而故意保留的缺陷模式。它们并非需要修复的错误。Python 服务与 .NET 服务保持一致，因此适用相同的参考答案。
